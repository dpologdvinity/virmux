# Security Policy

## Supported Versions

Only the latest release of `virmux` receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `virmux`, please report it responsibly:

1. **Do not open a public GitHub issue** for undisclosed security vulnerabilities.
2. Submit vulnerability details through GitHub Private Vulnerability Reporting at:  
   `https://github.com/dpologdvinity/virmux/security/advisories/new`
3. Alternatively, email the maintainer at `kaitlynbassford@gmail.com` with:
   - Detailed description of the vulnerability and attack vector.
   - Proof-of-concept (PoC) code or reproduction steps.
   - Potential impact on host systems, sandboxes, or user workspaces.

## Response Process

- We acknowledge vulnerability reports within **48 hours**.
- We assess severity and develop patches in private staging branches.
- Once verified, a patch release and public security advisory will be published with attribution.
